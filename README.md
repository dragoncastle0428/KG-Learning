# 🕸️ Knowledge Graph Implementation & Real-Data Learning Study

이 레포지토리는 지식 그래프(Knowledge Graph, KG)의 핵심 개념을 이해하고, 실제 데이터를 활용하여 직접 KG를 구축 및 학습하는 과정을 기록한 개인 스터디 공간입니다. 

단순한 트리플(Entity-Relation-Entity) 구조를 넘어, 복잡한 문맥과 속성을 담을 수 있는 고도화된 지식 그래프 모델링을 목표로 합니다.

## 🎯 Study Objectives (학습 목표)
1. **KG 기초 및 스키마 설계:** 속성 그래프(Labeled Property Graph, LPG) 및 하이퍼-릴레이셔널(Hyper-Relational) KG의 구조 이해
2. **컨텍스트 기반 모델링:** 5W1H (Who, What, When, Where, Why, How) 스키마를 적용한 데이터 모델링 실습
3. **LLM 기반 정보 추출:** 대형 언어 모델(LLM)을 활용한 비정형 데이터 내 엔티티 및 관계 자동 추출 파이프라인 구축
4. **실제 데이터 적용 및 학습:** 구축된 KG를 바탕으로 한 실데이터 학습 및 질의(Query) 검증

## 🛠️ Tech Stack (기술 스택)
* **Base:** `Python`, `Pandas`, `NumPy`
* **To Master (학습 목표):**
    * **Graph DB:** `Neo4j` (Cypher 쿼리 및 데이터베이스 구축)
    * **AI/ML:** `PyTorch`, `Hugging Face Transformers` (모델 학습 및 추론)
    * **LLM Pipeline:** `LangChain` (LLM-KG 연동 및 RAG 체인 구축)
